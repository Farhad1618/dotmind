The dots know what the model is doing

Plug in the model's stream and an 8 × 8 dot matrix follows along: a slow drift while it reasons, a radar sweep while it searches, a filling page while it writes. When text arrives faster, the dots move faster.

Looks

Pick a look and the same states draw different pictures. icons gives each job its own little icon and a soft glow; pixel draws square cells like an old LCD. The switch re-skins the replay above and every state below.

Every state

The tool's name decides the picture: web_search sweeps, run_sql lights disks, bash types between brackets. You can map your own tool names.

Use it

// React + Anthropic SDK
import { DotMind, useActivityTracker } from "dotmind/react";
import { followAnthropicStream } from "dotmind/anthropic";

const tracker = useActivityTracker();
const stream = client.messages.stream({ model, messages, tools });
followAnthropicStream(stream, tracker);

<DotMind tracker={tracker} />
// Vercel AI SDK: no tracker needed
import { aiSdkActivity } from "dotmind/ai-sdk";
const { messages, status } = useChat();

<DotMind activity={aiSdkActivity(messages, status)} />
<!-- Any framework, or none -->
<script type="module">import "dotmind/element/define";</script>
<dot-mind phase="tool" tool="web_search"></dot-mind>
